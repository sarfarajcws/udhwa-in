# udhwa-next

The public Udhwa website, built with Next.js 16. It reads all data from **udhwa-api** and holds no database credentials.

```bash
cp .env.example .env.local   # API_URL, site URLs, REVALIDATE_SECRET (same as the API)
npm install
npm run dev                  # http://localhost:3000 (udhwa-api must be running)
```

`npm run build` · `npm start` · `npm run lint` · `npm run typecheck` · `npm test` · `npm run e2e` (user flow, public pages + SEO audit, mobile + responsive; needs all three apps and udhwa-api's mock providers running — see the root README)

* `src/app/api/v1/[...path]` is a same-origin proxy to the API; sign-in and uploads go through it.
* `src/app/api/revalidate` is called by the API when published content changes.
* `src/lib/api-contract.ts` is generated by `udhwa-api` (`npm run contract`). Don't edit it by hand.

**Deploy:** Vercel, with root directory `udhwa-next`.
