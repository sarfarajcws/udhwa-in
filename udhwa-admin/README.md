# udhwa-admin

The Udhwa admin / CMS panel, built with Next.js 16. It manages content, moderation, users, media and redirects through **udhwa-api**. Access is limited to users with the ADMIN role, and the API checks this on every request.

```bash
cp .env.example .env.local   # API_URL and site URLs
npm install
npm run dev                  # http://localhost:3001 (udhwa-api must be running)
```

`npm run build` · `npm start` · `npm run lint` · `npm run typecheck` · `npm test` · `npm run e2e` (admin flow; needs all three apps and udhwa-api's mock providers running — see the root README)

* `src/app/api/v1/[...path]` is a same-origin proxy to the API, used for sign-in and uploads.
* `src/lib/api-contract.ts` is generated by `udhwa-api` (`npm run contract`). Don't edit it by hand.
* `public/seed/` holds the bundled seed photos, so previews of seeded content render.

**Deploy:** Vercel, with root directory `udhwa-admin`.
